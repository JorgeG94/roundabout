ice_frazil_accumulate_column_impl

private pure subroutine ice_frazil_accumulate_column_impl(c_T, c_S, h_layer, wet_mask, frazil_heat, heat_budget_frazil, eos, pressure_dependent, reclaim, nghost, nz, nx, ny)

Device kernel, one thread per PHYSICAL wet column, serial in k, scalars only. T, S, T_f are CT, SA and the CT liquidus under cons_abs (potential T/practical S otherwise); hc = rho c_p h with rho = RHO_WATER, c_p = eos%c_p (the same heat weight as the surface-only kernel and the console src term).

Pressure. With pressure_dependent, the layer-centre pressure is p_k = g rho0 (sum_{m>k} h_m + h_k/2) (Pa, surface pressure zero, rho0 = eos%rho0), summed top-down exactly as p = g rho0 h_nz/2, then += g rho0 (h_{m+1} + h_m)/2. Otherwise p = 0.

  1. Reclaim (reclaim). If the bank F = frazil_heat > 0 and the surface layer is above its T_f: with hc of the surface layer, F <= hc (T - T_f) cools it by F/hc and zeroes F; otherwise F -= hc (T - T_f) and T = T_f.
  2. Bottom-up sweep (k = 1 bed … nz surface) with a carry c = 0 (J/m2). A layer is visited when T < 1 degC (the cheap pre-check; every liquidus used is below that) or c > 0. A VANISHED layer (h <= H_VANISHED, the project dynamic-vanish threshold; layers at h <= H_DIV_EPS are skipped outright) can only freeze: T < T_f adds hc (T_f - T) to c and sets T = T_f. Any other layer, if c + hc (T_f - T) < 0 (warm enough to absorb the carry), cools by c/hc and zeroes c; else c += hc (T_f - T) and T = T_f. Frazil formed at depth therefore rises and is re-melted by warmer layers above; only what survives the top leaves the column.
  3. Hand-off. F += c (J/m2, positive = heat the ice model must spend, same sign and units as the surface-only kernel).

Conservation. The OCEAN heat change of the column is exactly c_final - F_reclaimed (J/m2); the kernel accumulates the true sum(h·Delta c_T) (K.m) into heat_budget_frazil, so the console src term (rho * budget) matches the bank change.

   pure subroutine ice_frazil_accumulate_column_impl(c_T, c_S, h_layer, wet_mask, &
                                                     frazil_heat, heat_budget_frazil, &
                                                     eos, pressure_dependent, reclaim, &
                                                     nghost, nz, nx, ny)
      !! Device kernel, one thread per PHYSICAL wet column, serial in k,
      !! scalars only.  T, S, T_f are CT, SA and the CT liquidus under
      !! `cons_abs` (potential T/practical S otherwise); `hc = rho c_p h`
      !! with `rho = RHO_WATER`, `c_p = eos%c_p` (the same heat weight as
      !! the surface-only kernel and the console `src` term).
      !!
      !! Pressure.  With `pressure_dependent`, the layer-centre pressure
      !! is `p_k = g rho0 (sum_{m>k} h_m + h_k/2)` (Pa, surface pressure
      !! zero, `rho0 = eos%rho0`), summed top-down exactly as
      !! `p = g rho0 h_nz/2`, then `+= g rho0 (h_{m+1} + h_m)/2`.
      !! Otherwise p = 0.
      !!
      !! 1. Reclaim (`reclaim`).  If the bank `F = frazil_heat > 0` and the
      !!    surface layer is above its T_f: with `hc` of the surface
      !!    layer, `F <= hc (T - T_f)` cools it by `F/hc` and zeroes F;
      !!    otherwise `F -= hc (T - T_f)` and `T = T_f`.
      !! 2. Bottom-up sweep (k = 1 bed ... nz surface) with a carry
      !!    `c = 0` (J/m2).  A layer is visited when `T < 1 degC` (the
      !!    cheap pre-check; every liquidus used is below that) or `c > 0`.
      !!    A VANISHED layer (`h <= H_VANISHED`, the project dynamic-vanish
      !!    threshold; layers at `h <= H_DIV_EPS` are skipped outright)
      !!    can only freeze: `T < T_f` adds `hc (T_f - T)` to c and sets
      !!    `T = T_f`.  Any other layer, if `c + hc (T_f - T) < 0` (warm
      !!    enough to absorb the carry), cools by `c/hc` and zeroes c;
      !!    else `c += hc (T_f - T)` and `T = T_f`.  Frazil formed at depth
      !!    therefore rises and is re-melted by warmer layers above; only
      !!    what survives the top leaves the column.
      !! 3. Hand-off.  `F += c` (J/m2, positive = heat the ice model must
      !!    spend, same sign and units as the surface-only kernel).
      !!
      !! Conservation.  The OCEAN heat change of the column is exactly
      !! `c_final - F_reclaimed` (J/m2); the kernel accumulates the true
      !! `sum(h·Delta c_T)` (K.m) into `heat_budget_frazil`, so the
      !! console `src` term (`rho * budget`) matches the bank change.
      integer, intent(in) :: nghost, nz, nx, ny
      real(wp), intent(inout) :: c_T(nx, ny, nz)
      real(wp), intent(in) :: c_S(nx, ny, nz)
      real(wp), intent(in) :: h_layer(nx, ny, nz)
      real(wp), intent(in) :: wet_mask(nx, ny)
      real(wp), intent(inout) :: frazil_heat(nx, ny)
      real(wp), intent(inout) :: heat_budget_frazil(nx, ny, 1)
      type(eos_t), intent(in) :: eos
      logical, intent(in) :: pressure_dependent, reclaim

      integer :: i, j, k, m, k_sfc, i_lo, i_hi, j_lo, j_hi
      real(wp) :: h, t_k, s_k, t_f, p_k, hc, c, f_bank, dsum, gr, new_t

      i_lo = nghost + 1
      i_hi = nx - nghost
      j_lo = nghost + 1
      j_hi = ny - nghost
      gr = GRAVITY*eos%rho0

      do concurrent(j=j_lo:j_hi, i=i_lo:i_hi) &
         local(k, m, k_sfc, h, t_k, s_k, t_f, p_k, hc, c, f_bank, dsum, new_t)
         k_sfc = rdb_vl_first_live(nx, ny, nz, h_layer, i, j, nz)
         if (wet_mask(i, j) > 0.5_wp .and. rdb_vl_is_live(h_layer(i, j, k_sfc))) then
            c = 0.0_wp
            dsum = 0.0_wp
            f_bank = frazil_heat(i, j)

            ! ---- 1. reclaim on the surface layer ----
            if (reclaim .and. f_bank > 0.0_wp) then
               h = h_layer(i, j, k_sfc)
               t_k = c_T(i, j, k_sfc)
               s_k = c_S(i, j, k_sfc)
               p_k = 0.0_wp
               if (pressure_dependent) p_k = 0.5_wp*gr*h
               t_f = eos_freezing_point(eos, s_k, p_k)
               if (t_k > t_f) then
                  hc = RHO_WATER*eos%c_p*h
                  if (f_bank <= hc*(t_k - t_f)) then
                     new_t = t_k - f_bank/hc
                     f_bank = 0.0_wp
                  else
                     f_bank = f_bank - hc*(t_k - t_f)
                     new_t = t_f
                  end if
                  dsum = dsum + h*(new_t - t_k)
                  c_T(i, j, k_sfc) = new_t
               end if
            end if

            ! ---- 2. bottom-up sweep with the carry ----
            do k = 1, nz
               h = h_layer(i, j, k)
               if (h <= H_DIV_EPS) cycle
               t_k = c_T(i, j, k)
               if (t_k < 1.0_wp .or. c > 0.0_wp) then
                  s_k = c_S(i, j, k)
                  p_k = 0.0_wp
                  if (pressure_dependent) then
                     p_k = 0.5_wp*gr*h_layer(i, j, nz)
                     do m = nz - 1, k, -1
                        p_k = p_k + 0.5_wp*gr*(h_layer(i, j, m + 1) + h_layer(i, j, m))
                     end do
                  end if
                  t_f = eos_freezing_point(eos, s_k, p_k)
                  hc = RHO_WATER*eos%c_p*h
                  if (.not. rdb_vl_is_live(h)) then
                     if (t_k < t_f) then
                        c = c + hc*(t_f - t_k)
                        dsum = dsum + h*(t_f - t_k)
                        c_T(i, j, k) = t_f
                     end if
                  else if (c > 0.0_wp .or. t_k < t_f) then
                     if (c + hc*(t_f - t_k) < 0.0_wp) then
                        new_t = t_k - c/hc
                        c = 0.0_wp
                     else
                        c = c + hc*(t_f - t_k)
                        new_t = t_f
                     end if
                     dsum = dsum + h*(new_t - t_k)
                     c_T(i, j, k) = new_t
                  end if
               end if
            end do

            ! ---- 3. hand-off ----
            frazil_heat(i, j) = f_bank + c
            heat_budget_frazil(i, j, 1) = heat_budget_frazil(i, j, 1) + dsum
         end if
      end do
   end subroutine ice_frazil_accumulate_column_impl
