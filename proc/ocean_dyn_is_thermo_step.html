ocean_dyn_is_thermo_step

private pure function ocean_dyn_is_thermo_step(this) result(yes)

Returns .true. if the thermodynamic / tracer kernels should fire on this outer step. dt_therm_ratio <= 1 (default) → always true (every step is a thermo step, bit-identical to prior behaviour). ratio >= 2 → fires every Nth step, aligned to outer_step_count = 0 for the IC snapshot (diabatic_first, default) or, with diabatic_first = .false., on the LAST step of each interval (outer_step_count + 1 a multiple of N: steps N, 2N, ...). The same function of the counter is read post-increment by the engine’s ice/flux block, so there the fluxes for the interval-end thermo step are prepared after step N-1.

   pure function ocean_dyn_is_thermo_step(this) result(yes)
      !! Returns `.true.` if the thermodynamic / tracer kernels should
      !! fire on this outer step.  `dt_therm_ratio <= 1` (default) →
      !! always true (every step is a thermo step, bit-identical to
      !! prior behaviour).  `ratio >= 2` → fires every Nth step,
      !! aligned to `outer_step_count = 0` for the IC snapshot
      !! (`diabatic_first`, default) or, with `diabatic_first = .false.`,
      !! on the LAST step of each interval (`outer_step_count + 1` a
      !! multiple of N: steps `N, 2N, ...`).  The same function of the
      !! counter is read post-increment by the engine's ice/flux block, so
      !! there the fluxes for the interval-end thermo step are prepared
      !! after step `N-1`.
      class(ocean_dyn_t), intent(in) :: this
      logical :: yes
      if (this%dt_therm_ratio <= 1) then
         yes = .true.
      else if (this%diabatic_first) then
         yes = (mod(this%outer_step_count, this%dt_therm_ratio) == 0)
      else
         yes = (mod(this%outer_step_count + 1, this%dt_therm_ratio) == 0)
      end if
   end function ocean_dyn_is_thermo_step
