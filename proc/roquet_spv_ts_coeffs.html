roquet_spv_ts_coeffs

public pure subroutine roquet_spv_ts_coeffs(T_pt, S_sp, sv0, sv1, sv2, sv3)

The (T, S)-dependent coefficients of the Roquet et al. (2015) SpV polynomial viewed as a polynomial in PRESSURE, in model variables (potential temperature T_pt degC, practical salinity S_sp PSU):

SV(p) = (sv0 + p(sv1 + p(sv2 + psv3))) + SV00p(p), SV00p(p) = p(ROQ_V00 + p(ROQ_V01 + … + pROQ_V05)),

with SV00p the (T, S)-independent reference profile. This is the value half of roquet_spv_point, term for term (same SR / CT conversion, same Horner nesting), with none of the derivative work: evaluating the expression above reproduces roquet_spv_point’s sv exactly.

WHY SPLIT. Everything expensive in the Roquet EOS – two sqrt, the degree-7 PT->CT polynomial and the ~50-term (zs, zt) sums – depends on T and S only. A caller that evaluates ONE parcel at several pressures (the FV-MOM6 in-situ PGF’s 5-point vertical Boole rule over a constant-T/S layer) calls this once and then pays only the degree-6 pressure Horner per point.

The body is rdb_roq_ts_coeffs (rdb_roquet_spv.inc, included here): kernel modules include the same file for a local, inlinable copy rather than calling this out-of-line entry point.
