roquet_rho_value

public pure function roquet_rho_value(T_pt, S_sp, p, cons) result(rho)

VALUE-ONLY Roquet et al. (2015) in-situ density (kg/m^3) at a point, model variables (PT degC, SP PSU, p Pa). The same number as roquet_rho_point’s rho without the d(rho)/dT, d(rho)/dS Horner work a density-only consumer (eos_density_point, the 3D fill kernel) would discard.

The body is rdb_roq_rho_ts_coeffs + rdb_roq_rho_p (rdb_roquet_rho.inc, included here): kernel modules include the same file (after the SpV inc) for a local, inlinable copy rather than calling this out-of-line entry point. Bit-identical to the hand-expanded form this function carried before the inc existed (same SR/CT conversion via the shared rdb_roq_ct_of helper, same Horner nesting, same evaluation order).

   pure function roquet_rho_value(T_pt, S_sp, p, cons) result(rho)
      !! VALUE-ONLY Roquet et al. (2015) in-situ density (kg/m^3) at a
      !! point, model variables (PT degC, SP PSU, p Pa).  The same
      !! number as `roquet_rho_point`'s `rho` without the d(rho)/dT,
      !! d(rho)/dS Horner work a density-only consumer
      !! (`eos_density_point`, the 3D fill kernel) would discard.
      !!
      !! The body is `rdb_roq_rho_ts_coeffs` + `rdb_roq_rho_p`
      !! (`rdb_roquet_rho.inc`, included here): kernel modules include the
      !! same file (after the SpV inc) for a local, inlinable copy rather
      !! than calling this out-of-line entry point. Bit-identical to the
      !! hand-expanded form this function carried before the inc existed
      !! (same SR/CT conversion via the shared `rdb_roq_ct_of` helper, same
      !! Horner nesting, same evaluation order).
      !$acc routine seq
      logical, intent(in) :: cons
         !! `.true.` = (T, S) are already (CT, SA) (`TS_CONS_ABS`): no SR
         !! factor, no PT->CT conversion, unit Jacobian.
      real(wp), intent(in) :: T_pt, S_sp, p
      real(wp) :: rho

      real(wp) :: r0, r1, r2, r3

      call rdb_roq_rho_ts_coeffs(T_pt, S_sp, r0, r1, r2, r3, cons)
      rho = rdb_roq_rho_p(r0, r1, r2, r3, p)
   end function roquet_rho_value
