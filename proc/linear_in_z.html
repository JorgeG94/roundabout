linear_in_z

private pure elemental function linear_in_z(v_ref, dv_dz, z_depth) result(v)

Affine profile v(z) = v_ref + dv_dz*z evaluated at geopotential height z = -z_depth, i.e. v = v_ref - dv_dz*z_depth.

z is positive UP with the origin at the z = 0 datum, which is the convention &ocean_ic_nml eady_dT_dz already uses. A STABLE thermal column therefore has dv_dz > 0 for temperature (warm on top) and dv_dz < 0 for salinity (salty at the bed).
