seed_land_tracer_hold_impl

pure subroutine seed_land_tracer_hold_impl(c, wet_mask, nz)

Hold the tracer concentration c at ZERO on land T-cells (wet_mask == 0) so the masked dyn-core never evaluates 0*NaN. Wet cells untouched (bit-identical when wet_mask ≡ 1).

Land-state contract: h = H_VANISHED, c = 0. A land column contributes h*c = 0 to every budget and every console total, at the latch and at every later step. No operator rewrites a retained c on a layer it does not fill, so the value is held, not re-derived each step.

   pure subroutine seed_land_tracer_hold_impl(c, wet_mask, nz)
      !! Hold the tracer concentration `c` at ZERO on land T-cells
      !! (`wet_mask == 0`) so the masked dyn-core never evaluates `0*NaN`.
      !! Wet cells untouched (bit-identical when `wet_mask ≡ 1`).
      !!
      !! Land-state contract: `h = H_VANISHED`, `c = 0`.  A land column
      !! contributes `h*c = 0` to every budget and every console total, at
      !! the latch and at every later step.  No operator rewrites a
      !! retained `c` on a layer it does not fill, so the value is held, not
      !! re-derived each step.
      integer, intent(in) :: nz
      real(wp), intent(inout) :: c(:, :, :)
      real(wp), intent(in) :: wet_mask(:, :)
      integer :: i, j, k, nx, ny
      nx = size(c, 1)
      ny = size(c, 2)
      do k = 1, nz
         do j = 1, ny
            do i = 1, nx
               if (wet_mask(i, j) == 0.0_wp) c(i, j, k) = 0.0_wp
            end do
         end do
      end do
   end subroutine seed_land_tracer_hold_impl
