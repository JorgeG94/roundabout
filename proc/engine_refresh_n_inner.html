engine_refresh_n_inner

private subroutine engine_refresh_n_inner(engine, dt, t)

Re-derive the barotropic substep count from the LIVE layer thicknesses (&ocean_bt_nml dtbt, dtbt_reset_period >= 0): the domain minimum of rdb_barotropic_dtbt’s dt_max over wet cells, reduced across ranks so every rank runs the same count. Period 0 recomputes every call; period P > 0 when t reaches the next multiple of P (and at the first call). n_inner is a pure function of the state (h_layer, f, metrics), so a restart that re-derives at its first step reproduces it for period 0.

Multi-rank invariant. The reduction runs over OWNED cells, but each cell’s limit reads h_layer at its four neighbours, so ghost thickness enters through every seam face. Those ghosts are already valid here by construction: the previous step ended on a stage-end exchange followed by full-array averaging / ALE remap (or the setup exchange, on the first step) – an invariant the whole bit-identity gate relies on, since ocean_porous_refresh and several routines at the head of the dyn step read start-of-step ghosts before the first stage exchange. The refresh below is DEFENSIVE: it makes this reduction independent of that invariant, using the stage-entry sequence verbatim (ocean_halo_exchange_ml_state, periodic wrap on an axis the exchange does not own, tripolar fold). The ghosts are already exact images, so it rewrites identical values and changes no state: a dtbt_reset_period > 0 run cannot depend on where the reset steps fall. Collective when decomposed; the schedule depends only on t and config, so every rank calls it on the same steps. The min over ranks is exact, hence rank-count independent.

   subroutine engine_refresh_n_inner(engine, dt, t)
      !! Re-derive the barotropic substep count from the LIVE layer
      !! thicknesses (`&ocean_bt_nml dtbt`, `dtbt_reset_period >= 0`): the
      !! domain minimum of `rdb_barotropic_dtbt`'s `dt_max` over wet cells,
      !! reduced across ranks so every rank runs the same count.  Period 0
      !! recomputes every call; period `P > 0` when `t` reaches the next
      !! multiple of `P` (and at the first call).  `n_inner` is a pure
      !! function of the state (`h_layer`, `f`, metrics), so a restart that
      !! re-derives at its first step reproduces it for period 0.
      !!
      !! **Multi-rank invariant.**  The reduction runs over OWNED cells, but
      !! each cell's limit reads `h_layer` at its four neighbours, so ghost
      !! thickness enters through every seam face.  Those ghosts are already
      !! valid here by construction: the previous step ended on a stage-end
      !! exchange followed by full-array averaging / ALE remap (or the setup
      !! exchange, on the first step) -- an invariant the whole bit-identity
      !! gate relies on, since `ocean_porous_refresh` and several routines at
      !! the head of the dyn step read start-of-step ghosts before the first
      !! stage exchange.  The refresh below is DEFENSIVE: it makes this
      !! reduction independent of that invariant, using the stage-entry
      !! sequence verbatim (`ocean_halo_exchange_ml_state`, periodic wrap on
      !! an axis the exchange does not own, tripolar fold).  The ghosts are
      !! already exact images, so it rewrites identical values and changes no
      !! state: a `dtbt_reset_period > 0` run cannot depend on where the
      !! reset steps fall.  Collective when decomposed; the schedule depends
      !! only on `t` and config, so every rank calls it on the same steps.
      !! The `min` over ranks is exact, hence rank-count independent.
      type(ocean_engine_t), intent(inout) :: engine
      real(wp), intent(in) :: dt
      real(wp), intent(in) :: t
      integer :: ng, n_new
      real(wp) :: dt_loc, dt_glob

      if (engine%dtbt_reset_period > 0.0_wp) then
         if (t < engine%dtbt_next_t) return
         engine%dtbt_next_t = (floor(t/engine%dtbt_reset_period) + 1.0_wp)* &
                              engine%dtbt_reset_period
      end if
      ng = engine%grid%nghost
      call ocean_halo_exchange_ml_state(engine%state%multilayer)
      call ocean_periodic_wrap_state(engine%grid, engine%state%bc, engine%state%multilayer, &
                                     skip_x=ocean_halo_is_decomposed_x(), &
                                     skip_y=ocean_halo_is_decomposed_y())
      call ocean_fold_wrap_state(engine%grid, engine%state%bc, engine%state%multilayer)
      call bt_dtbt_dt_max(engine%grid%nx_total, engine%grid%ny_total, &
                          size(engine%state%multilayer%h_layer, 3), &
                          ng + 1, ng + engine%grid%nx_phys, ng + 1, ng + engine%grid%ny_phys, &
                          engine%state%multilayer%h_layer, engine%state%metrics%wet_T, &
                          engine%state%metrics%dy_cu_bt, engine%state%metrics%dx_cv_bt, &
                          engine%state%metrics%idxCu, engine%state%metrics%idyCv, &
                          engine%state%metrics%iareaT, engine%state%coriolis_adv%f_corner, &
                          engine%state%dyn%bt_work%g_bt, engine%dtbt_bebt, .true., dt_loc)
      call halo_allreduce_min(dt_loc, dt_glob)
      n_new = bt_dtbt_n_inner(dt, engine%dtbt, dt_glob)
      if (n_new /= engine%n_inner) then
         call logger%info("dtbt: dt_max = "//to_string(dt_glob)//" s at t = "// &
                          to_string(t)//" -> n_inner "//to_string(engine%n_inner)// &
                          " -> "//to_string(n_new))
         engine%n_inner = n_new
      end if
   end subroutine engine_refresh_n_inner
