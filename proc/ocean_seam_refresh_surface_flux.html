ocean_seam_refresh_surface_flux

public subroutine ocean_seam_refresh_surface_flux(sf, grid, bc, device_resident)

Seam ghosts of the ASSEMBLED Q_heat / Q_salt: one centre exchange each (MPI, or the periodic wrap on one rank) plus the tripolar fold.

Why. The assembler sums components over the whole array, but a physical-span-only filler (the bulk consumer, a data-override reader, the ice-shelf cavity bands) leaves its components’ ghosts stale, so the ghost Q_heat/Q_salt lacks that part. KPP and EPBL loop the full array and read the flux in the ghost columns (B_0), set kv there, and the momentum viscosity averages the ghost-column kv into the first owned face: a decomposed run then differs from the serial one, and the serial periodic seam from the interior. Exchanged, never extrapolated. Call right after ocean_surface_flux_assemble (same thermo cadence); a no-op unless sf%use_components, and unconditional beyond that (no per-filler flag: where the ghosts are already right it rewrites identical bits). Both fields are scalars: no sign flip at the fold.

   subroutine ocean_seam_refresh_surface_flux(sf, grid, bc, device_resident)
      !! Seam ghosts of the ASSEMBLED `Q_heat` / `Q_salt`: one centre exchange
      !! each (MPI, or the periodic wrap on one rank) plus the tripolar fold.
      !!
      !! **Why.**  The assembler sums components over the whole array, but a
      !! physical-span-only filler (the bulk consumer, a data-override
      !! reader, the ice-shelf cavity bands) leaves its components' ghosts stale,
      !! so the ghost `Q_heat`/`Q_salt` lacks that part.  KPP and EPBL loop the full array
      !! and read the flux in the ghost columns (`B_0`), set `kv` there, and
      !! the momentum viscosity averages the ghost-column `kv` into the first
      !! owned face: a decomposed run then differs from the serial one, and
      !! the serial periodic seam from the interior.  Exchanged, never
      !! extrapolated.  Call right after `ocean_surface_flux_assemble`
      !! (same thermo cadence); a no-op unless `sf%use_components`, and unconditional
      !! beyond that (no per-filler flag: where the ghosts are already right it
      !! rewrites identical bits).  Both fields are scalars: no sign flip at the fold.
      type(ocean_surface_flux_t), intent(inout) :: sf
      type(hgrid_t), intent(in) :: grid
      type(ocean_bc_state_t), intent(in) :: bc
      logical, intent(in), optional :: device_resident

      if (.not. sf%use_components) return
      call profiler_start("ocean_comms_flux")
      call ocean_halo_exchange_centre_field(sf%Q_heat, grid, bc, device_resident)
      call ocean_halo_exchange_centre_field(sf%Q_salt, grid, bc, device_resident)
      call profiler_stop("ocean_comms_flux")
   end subroutine ocean_seam_refresh_surface_flux
