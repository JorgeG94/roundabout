roquet_rho_ts_coeffs

public pure subroutine roquet_rho_ts_coeffs(T_pt, S_sp, r0, r1, r2, r3, cons)

The (T, S)-dependent coefficients of the Roquet et al. (2015) in-situ-DENSITY polynomial viewed as a polynomial in PRESSURE, in model variables (potential temperature T_pt degC, practical salinity S_sp PSU):

rho(p) = (r0 + p(r1 + p(r2 + pr3))) + R00p(p), R00p(p) = p(ROQ_RHO_R00 + p(ROQ_RHO_R01 + … + pROQ_RHO_R05)),

with R00p the (T, S)-independent reference profile. This is the value half of roquet_rho_point, term for term (same SR / CT conversion, same Horner nesting, ΔS = 32 vs the SpV fit’s 24), with none of the derivative work.

The body is rdb_roq_rho_ts_coeffs (rdb_roquet_rho.inc, included here): kernel modules include the same file (after the SpV inc, for the shared rdb_roq_ct_of helper) for a local, inlinable copy rather than calling this out-of-line entry point.
