Drives the conservative vertical remap of multilayer.h_layer + every registered multilayer.tracers(t)%c from the current (Lagrangian) grid to vcoord%target_h. The kernel is the per-column remap_column from rdb_remap_column (shared with coastal); this module wires it across the registered tracer slot list plus the face-velocity pass.

Per-column conservation: sum_k(h*c) is preserved to round-off (the content the bounding moves and the few-ulp sliver of a column-total mismatch land in the remap budget slot, which is how they are measured).

The tracer remap computes on the stored CONCENTRATION (White & Adcroft 2008; Griffies et al. 2020). The PPM reconstruction (Colella & Woodward 1984) and the overlap integral run on c, giving c_new directly; a vanished source layer is just a cell value in the stencil (it keeps its last c); the target is bounded by the source cells that contributed, and an empty target takes the mean of the source cell containing its bottom interface. There are no read/write pool merges and no defect fold around the kernel.

public pure function remap_use_stream(vcoord, nz, method, bnd_extrap, nonunif) result(use_stream)

Host-side dispatch of the tracer remap: .true. when the streaming kernel (ocean_remap_tracer_field_stream) can and should run. The stream implements exactly the default PPM column (REMAP_PPM, nz >= 3, uniform-weight edges, PCM boundary cells) and needs its global scratch buffers; everything else (other methods, nz <= 2, remap_boundary_extrap, remap_nonuniform_weights, &vcoord_nml remap_kernel = "reference") takes the stack-based reference kernel. The stream kernel itself contains no call into stack-based code, hence the decision is taken here, not per column.

public pure subroutine ocean_remap_tracer_field(nx, ny, nz, h_old, h_new, c, method, bnd_extrap, nonunif, budget, c_new_out, clamp_out)

Flat-impl REFERENCE tracer remap on the stored concentration. Per (i,j) column: donor-substituted c_don (rdb_vl_column_conc) → per-column remap kernel on c_don → each filler’s excess c_old − c_don added back over its overlap (remap_add_filler_excess) → bounding + empty-target fallback (remap_bound_column) → c = c_new. A filler’s stale value never enters a live cell’s reconstruction stencil, and the column content sum(h_old·c_old) is conserved exactly. budget (optional): the per-cell h_new·c_new − h_old·c_old increment (two standalone products) is accumulated into the slot (heat/salt remap deltas) before overwriting. Flat-arg so GPU codegen doesn’t chase the array-of-derived-types pointer.

private pure subroutine remap_add_filler_excess(nz, h_old_col, h_new_col, c_don, c_own, c_new)

Reference-path half of the filler rule (the stream kernel 2 shifts the filler’s parabola instead). The column kernel ran on the donor-substituted c_don; each source filler m (0 < h_old <= H_VANISHED) owns h_old(m)·(c_own(m) − c_don(m)) more, carried as a uniform offset over its interval: every target k with h_new > 0 gains s·overlap/h_new(k). Exactly restores sum(h_old·c_own). A column without fillers is untouched (bit-identical).

private pure subroutine remap_bound_column(nz, h_old_col, h_new_col, c_old, c_own, c_new, clamp_amt, bnd_extrap)

Concentration-form closure of one remapped column (reference path; the stream kernel 3 does the same per cell). For each target layer k, with the source cells that CONTRIBUTE to it (overlap > 0 and h_old > 0, exactly the cells the overlap integral adds up): * h_new(k) > 0 and at least one contributor: clamp c_new(k) to [min, max] of c_old over the contributors’ reconstruction stencils (each contributor ko with ko-1 and ko+1) — the bounding of White & Adcroft (2008) / Griffies et al. (2020). Analytically a no-op for a Colella & Woodward (1984) limited parabola, which cannot leave its stencil’s range (bounding by the contributor MEANS alone would flatten every target inside one source cell to PCM); it removes the O(eps·|c|·h_src/h_new) overshoot a few-ulp-thin target can pick up in the quotient. A non-finite raw value is left alone (an if/else clamp would launder it into a plausible lo/hi). * h_new(k) <= 0, or no contributor (a sliver above the source column): c_new(k) is the mean of the source cell containing the target’s bottom interface (the topmost cell if it lies above the column) — the water that interface sits in, never a made-up 0. clamp_amt(k) = h_new(k)·(c_new_final − c_new_raw) is the content the closure moves; it is part of h_new·c_new − h_old·c_old, hence of the remap budget slot.

private pure subroutine rescale_anomaly_ke(nz, h_old_face, h_new_face, u_old_col, u_new_col)

KE-conserving rescale of a remapped face-velocity column. The column remap conserves momentum (Σ h·u) but not KE; restore it by rescaling ONLY the baroclinic anomaly (Adcroft & Hallberg 2006): scale = sqrt(KE_old_anom/KE_new_anom), clamped to [0, 1.25] u_new(k) = u_bar_new + scale·(u_new(k) - u_bar_new) Barotropic mean u_bar preserved verbatim; degenerate columns untouched.
