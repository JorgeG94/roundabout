A caller building an initial condition in memory (Python’s Model.stage_h / stage_u / stage_v / stage_tracer, or a Fortran caller filling ocean_engine_t%staged_* directly) hands the library interior-sized arrays in the pending-create window. engine_setup calls ocean_ic_apply_staged ONCE, right after the built-in IC seed and BEFORE the sponge reference snapshot, so every setup-time snapshot and derivation (sponge ref_tracer/u_ref/v_ref, land-face masking, tidal-mixing fold, wet/dry mask, the init-time seam exchange and enter_data) sees the user’s fields instead of the built-in ones.

Everything here is HOST-side plain do loops: the call precedes ocean_state_enter_data, so no device copies exist yet and none are made (mem:separate safe by construction).

Order (load-bearing)

  1. h first — validated (finite, h > 0 on wet cells; column sum within IC_H_COLUMN_RTOL of the water column). Tracers NOT staged keep their CONCENTRATION: hTr is rescaled by h_new/h_old.
  2. Staged tracers: hTr = conc * h (the product rdb_ocean_set_tracer forms), against the NEW h, so staging order is irrelevant.
  3. u / v on the interior faces.
  4. Ghosts: periodic wrap on a periodic axis, zero-gradient at every other edge (never h = 0 ghosts: the EOS would fall back to rho0 and manufacture a density jump at wall-adjacent faces).
  5. Pseudo-salt re-seeded from S unless pseudo-salt itself was staged.
  6. EOS, gated by thermo_active exactly as the step gates it, so rho_layer is current for the sponge snapshot while a prescribed layer_rho_init is left alone when thermodynamics are off.

Nothing staged => the first statement returns: bit-identical to the ordinary create.

Single-rank only: staged arrays are the whole (global) interior.

real(kind=wp), public, parameter :: IC_H_COLUMN_RTOL = 0.25_wp

Largest accepted |sum_k h - D| / D on a wet column, D the water column (b, or b - z_draft under an ice shelf). A real free surface moves a column by O(1 m) against kilometres of water, so 25 % admits every physical sea-surface height and every thin-shelf column, while catching what staging mistakes actually look like: h in the wrong units (cm, fractions of the depth), the wrong nz-ordering of a layer-thickness profile, or an array that never summed to the bathymetry that was staged with it.

public subroutine ocean_ic_apply_staged(state, grid, staged_h, staged_u, staged_v, staged_tracers, per_x, per_y, thermo_active, ierr)

public subroutine ocean_ic_fill_state_ghosts(state, grid, per_x, per_y, fill_h, fill_u, fill_v, tracer_mask, all_tracers)

Fill the ghost bands of the host multilayer state from its interior: periodic image on a periodic axis, zero-gradient elsewhere (never h = 0 ghosts, see the module docstring). HOST plain loops, so it is correct before enter_data (the staged path) AND on the live handle (ocean_rebaseline_apply pushes the result to the device afterwards). With every optional absent it fills h, u, v and every tracer.
