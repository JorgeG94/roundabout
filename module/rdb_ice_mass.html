Ports of the subset of the Winton (2000) resize step needed by the Winton column step: bottom freezing, top/bottom melt peel, and equal-mass layer rebalancing (rebalance_ice_layers, Winton 2000). The equal-mass repartition follows the column-thermodynamics description of Winton (2000) and the CICE v5 user guide (Hunke et al. 2015).

PR 26 ports the snow source term (ice_snow_accumulate, below) — the first branch CICE-family runs in the resize step (Winton 2000 column order), so it sits first in this module too. PR 27 ports the Archimedes freeboard snow-ice flooding conversion (ice_snow_ice_flood, below) — the FINAL substantive block of the resize step (Archimedes flooding), so it sits last in this module too. Pond/evap/rain mass paths remain deliberately NOT ported. TODO(PR-35): pond mass paths. Evap/rain need atmospheric fields Roundabout does not carry (PR-55 at the earliest).

All procedures pure, !$acc routine seq, explicit-shape, TOP-DOWN columns (index 0 = snow, 1..nk = ice top->bottom) — identical convention to rdb_ice_column.

public pure subroutine ice_bottom_freeze(nk, m_lay, enthalpy, salin, bmelt, enth_ocean, salin_freeze, h2o_ocn_to_ice)

Bottom-freezing branch of the resize step (Winton 2000, bottom freezing). When bmelt < 0 (net upward heat deficit at the base), freeze ocean water onto the bottom ice layer: enth_freeze = min(enthalpy(nk), enth_ocean - min_denth_freeze), m_freeze = -bmelt/(enth_ocean - enth_freeze), mass-weighted mix of the bottom layer’s enthalpy + salinity, bmelt reset to 0.

public pure subroutine ice_bottom_melt_peel(nk, m_lay, enthalpy, salin, bmelt, heat_to_ocn, h2o_ice_to_ocn, m_ice_share)

Bottom melt peel (Winton 2000, bottom melt peel; prototype Hunke et al. 2015 melt-energy accounting). Same peel as ice_top_melt_peel but from k=nk down to k=0. The prototype’s separate ablation return is dropped (it is h2o_ice_to_ocn restricted to this call; PR 3b can re-derive it if needed).

public pure subroutine ice_rebalance_layers(nk, m_lay, enthalpy, salin, mtot_ice)

Equal-mass repartition of ice layers 1..nk, mass-weighting enthalpy and salinity (Winton 2000 equal-mass repartition; prototype Hunke et al. 2015 layer rebalancing). The snow slot (m_lay(0), enthalpy(0)) is untouched. mtot_ice = sum(m_lay(1:nk)) is returned; mtot_ice == 0 is an early exit leaving the ice layers untouched (there is no ice to rebalance). The k1/k2 two-pointer drain loop follows the CICE-family/prototype branch order exactly, including the (m_ice_avg - mlay_new(k2) > src_m(k1)) .or. (k2 == nk) test.

public pure subroutine ice_snow_accumulate(nk, m_lay, snow)

Snow source-term branch of the resize step (Winton 2000 column order): m_lay(0) = m_lay(0) + snow. The snow layer’s specific enthalpy enthalpy(0) is UNCHANGED by snowfall – the CICE convention notes this “should do nothing” (CICE v5 user guide, snowfall energy) and books the implied energy against the atmosphere (enth_snowfall = snow*enthalpy(0) -> Enth_Mass_in_atm). Roundabout’s atmosphere is a prescribed slab with no energy budget to charge, so that bookkeeping is not ported – a documented v1 divergence (PLAN_PR26_snowfall.md, S3).

public pure subroutine ice_top_melt_peel(nk, m_lay, enthalpy, salin, tmelt, heat_to_ocn, h2o_ice_to_ocn, m_ice_share)

Top melt peel (Winton 2000, top melt peel; prototype Hunke et al. 2015 melt-energy accounting). Peels mass from k=0 (snow) upward through k=nk until tmelt is spent; a massless layer is skipped; the partial layer takes m_melt = melt_left/(enth_fr - enthalpy); any leftover melt energy (all layers exhausted) drains to heat_to_ocn. Snow/pond-free path — tmelt is assumed already >= 0 on entry (the caller folds any negative top-melt into bmelt upstream, Hunke et al. 2015, top-melt folding).
