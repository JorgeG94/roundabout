Per-column first-baroclinic internal gravity-wave speed cg1 (m/s) and first-mode Rossby radius Rd (m), plus Rd/dx (the GM/Redi/MEKE resolution ratio). Solves the rigid-lid Sturm-Liouville eigenproblem discretised from layer thicknesses and per-interface reduced gravities gprime = (g/rho0)*max(0,drho) (rho_layer authoritative); largest c^2 via a fixed-budget Sturm-count bisection (no early exit -> warp-divergence-free). Reference: Chelton et al. (1998).

Vertical ordering (load-bearing): rdb is bottom-up (k=1 bed, k=nz surface); the eigensolve is surface-down so the column kernel FLIPS on gather (local k_loc=1 is the surface layer).

Diagnostic, default off (&ocean_wavespeed_nml enable=.false.) ⇒ kernel never called, bit-identical.

public pure function wavespeed_rd(cg1, fabs, beta) result(rd)

public pure subroutine wavespeed_cg1_column(nz, h_rak, rho_rak, rho0, cg1)

First-baroclinic wave speed for ONE column. h_rak/rho_rak are in Roundabout ordering (k=1 bed, k=nz surface), fixed-size NZ_STACK_MAX arrays; only 1..nz are read. Returns cg1 (m/s), 0 for land / homogeneous / kc<2 / sub-floor columns. Gathers+flips surface-down, backtracking convective merge, symmetric tridiag, fixed-budget Sturm-count bisection.

public pure subroutine wavespeed_compute(grid, metrics, this, ms)

Fill this%cg1, this%rd, this%rd_over_dx over the domain. rho_layer is a top-level allocatable that reaches the device directly, so no outer-shim tracer dereference is needed (unlike EPBL/kappa-shear). Call at the n_wavespeed cadence. Host guards + dereference here; the explicit-shape do concurrent kernel lives in wavespeed_compute_impl (outer-shim + flat-impl pattern — mirrors varmix_compute).
