Per-column first-baroclinic internal gravity-wave speed cg1 (m/s) and first-mode Rossby radius Rd (m), plus Rd/dx (the GM/Redi/MEKE resolution ratio). Solves the rigid-lid Sturm-Liouville eigenproblem discretised from layer thicknesses and per-interface reduced gravities gprime = (g/rho0)*max(0,drho) (rho_layer authoritative); largest c^2 via a fixed-budget Sturm-count bisection (no early exit -> warp-divergence-free). Reference: Chelton et al. (1998).

Optional equivalent-barotropic (EBT) mode (use_ebt): the gravest PRESSURE mode of the same layered Sturm-Liouville problem (Killworth, Chelton & de Szoeke 1997; de Szoeke & Chelton 1999; Killworth & Blundell 2003), used as the vertical shape of mesoscale eddy stirring (Hallberg 2013). Unknowns live at the kc LAYER centres of the committed (merged) stack; surface Neumann, bed Dirichlet (p’=0 at the bed interface, half-cell ghost). Gives the speed cg1_ebt = 1/sqrt(lambda_min) (-> 2NH/pi for constant N, twice the first-baroclinic NH/pi) and the one-signed structure ebt_struct(i,j,k), normalised to 1 at the surface, remapped conservatively (PLM) from the merged stack onto the raw layers.

Vertical ordering (load-bearing): rdb is bottom-up (k=1 bed, k=nz surface); the eigensolve is surface-down so the column kernel FLIPS on gather (local k_loc=1 is the surface layer).

Diagnostic, default off (&ocean_wavespeed_nml enable=.false.) ⇒ kernel never called, bit-identical.

public pure subroutine wavespeed_compute(grid, metrics, this, ms)

Fill this%cg1, this%rd, this%rd_over_dx over the domain (and cg1_ebt + ebt_struct when use_ebt). rho_layer is a top-level allocatable that reaches the device directly, so no outer-shim tracer dereference is needed (unlike EPBL/kappa-shear). public pure subroutine wavespeed_mode_column(nz, h_rak, rho_rak, rho0, use_ebt, cg1, cg1_ebt, phi_rak)

First-baroclinic wave speed cg1 and (when use_ebt) the equivalent-barotropic speed cg1_ebt + structure phi_rak for ONE column. h_rak/rho_rak/phi_rak are in Roundabout ordering (k=1 bed, k=nz surface), fixed-size NZ_STACK_MAX arrays; only 1..nz are read/written. cg1 is 0 for land / homogeneous / kc<2 / sub-floor columns; those columns also get cg1_ebt = 0 and phi_rak = 0 (structure 0, not 1). With use_ebt = .false., cg1_ebt/phi_rak are set to 0 and the cg1 arithmetic is untouched (bit-identical). Gathers+flips surface-down, backtracking convective merge, tridiag, fixed-budget Sturm-count bisection.

private pure subroutine wavespeed_compute_impl(nx, ny, nz, rho0, use_ebt, h_layer, rho_layer, wet_mask, f_centre, beta_centre, dxT, cg1, rd, rd_over_dx, cg1_ebt, nze, ebt_struct)

Flat-impl wavespeed kernel (explicit-shape; NVHPC descriptor-walk-free). Per-column Sturm-Liouville solve (wavespeed_cg1_column) + the deformation-radius blend (wavespeed_rd), then the metres-denominated resolution ratio rd_over_dx = rd / dxT. With use_ebt, the same column launch also writes cg1_ebt and ebt_struct (0 on land / degenerate columns); with it off neither is touched.
