Reads pre-regridded T + S from a model-grid NetCDF file (&ocean_zinit_nml), interpolates linearly in depth onto the seeded layer-centre depths, and writes the multilayer tracer slots as hTr = value * h_layer.

  • File is PRE-REGRIDDED to nx_phys x ny_phys — no in-core horizontal interpolation.
  • Vertical interp is point-linear-in-depth, constant extrapolation beyond the source range.
  • Dry columns (wet_mask <= 0) get the namelist land_fill_t/_s constants.

Runs at seed time, HOST-side, BEFORE ocean_state_enter_data, so it uses plain host do loops (NOT do concurrent); the later enter_data copies the host-resident arrays up. NetCDF-only.

private function zinit_io_ok(local_ierr, ierr, ncid) result(ok)

Translate a raw nc_check-style status (0 = ok) from one of the nc_* reader calls in seed_ts_from_zfile/read_dims into the caller’s ierr contract: .true. on success; on failure, .false. with ierr = OCEAN_STATUS_ERR_IO when ierr is present (closing ncid first, when given, so a mid-read failure does not leak the file handle), or error stops with the SAME generic text nc_check itself would have used had ierr never been threaded through — keeps the legacy (no ierr) behaviour byte-identical while unblocking the ierr-present return path (F1/F2 of the P0.1 review).

public subroutine seed_ts_from_zfile(ms, grid, cfg, ierr)

Read T/S from the configured z-level NetCDF and overwrite the tracer slots with the depth-interpolated profiles. Wet columns interpolate; dry columns get the namelist land-fill constants. Must be called AFTER bathymetry, the uniform h_layer seed, and wet_mask are in place. Takes the multilayer slot directly (not the full ocean state) to avoid a circular dependency.
