Rank-uniform verdicts at configure time need GLOBAL quantities: a test on a tile’s own cells lets one rank refuse (or return before a collective) while its neighbours carry on, and the job then hangs or reduces garbage. These wrappers reduce over the compute communicator ONLY when the grid is a tile of a larger domain (nx_phys < nx_global or ny_phys < ny_global) and are the identity otherwise.

The identity case is load-bearing twice: unit tests build a state with no communicator initialised (a reduction would fault), and the bit-identity gate runs a serial reference (compute_size = 1, a global grid) on EVERY physical rank, where a reduction over the real communicator would sum nprocs copies of one problem.

The tiled test depends only on the decomposition, which every rank agrees on, so all ranks take the same branch.
