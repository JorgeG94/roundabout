register_default_tracers

Overlay of the scalar &tracer_nml configuration onto the salinity / temperature slots of a tracer_t registry.

Historically this module also carried the A-grid coastal state_t god-object; the ocean path composes ocean_state_t instead (src/core/ocean/state/rdb_ocean_state.F90), so all that survives here is the registry overlay both the driver and the benches call at setup.

public subroutine register_default_tracers(tr_S, tr_T, cfg)

Overlay scalar config onto the already-allocated salinity / temperature tracer slots (by reference, so every caller shares the overlay). Does not touch hTr / hTr0 — those are populated by the path’s IC step once h_layer is known.
