Shadow state for the wide-halo barotropic march-in. When bt_halo > 0, the BT fast loop runs on WIDE arrays with ghost width ng_wide = nghost + bt_halo. Ghost cells outside the valid band evolve stale data that creeps INWARD at one cell per substep; one PACKED exchange (a single message per neighbour per direction pass for eta, ubt, vbt and, with bebt > 0, ubt_prev/vbt_prev) every bt_wide_cycle_len(ng_wide) = ng_wide - 2 substeps (ng_wide = nghost + W, W = bt_halo rounded down to even) keeps the owned cells exact (proven limit ng_wide - 1; one substep of margin). The per-solve entry set (eta, ubt, vbt, rem, force) is one packed exchange too, the static H_ref is exchanged once, and the normal-width time means, end-of-loop snapshots and transports leave in one packed exit exchange. The mid-substep u exchange is absorbed. Proof: owned cells are bitwise equal to the one-rank run with every invalidated layer poisoned between exchanges (RDB_BT_INHALO_POISON, test_ocean_dyn_mpi), and the cadence one substep past the limit breaks them.

Tripolar north fold (Murray 1996 bipolar cap): the north band is NOT an invalid-front edge. The fast loop folds the whole nghost + bt_halo row band EVERY substep, at the two points the bt_halo = 0 loop folds (the fold-line v row is projected from its mirror each substep, which a locally evolved band could not reproduce bitwise): inline at px = 1, through the owner-routed exchange on the wide plan (FOLD_CTX_WIDE of rdb_ocean_fold_exchange) at px > 1. Static fields beyond the fold: the outer bt_halo rows are clamped copies that are never read (the ring poison covers them); the first nghost rows beyond the fold are the model’s own already-folded ghost rows and ARE read, exactly as at bt_halo = 0 (the RDB_BT_RING_POISON=132 control poisons the static and dynamic fields of the innermost folded ghost row and fails, which shows that the ROW is read, not which field). Every dynamic row beyond the fold is refolded each substep.

Lifecycle: 1. init — allocate wide arrays; fill the STATIC wide metrics and f_corner from the model’s own arrays (host, once). 2. enter_data — attach all wide arrays to the GPU present table. 3. Per outer step: copy_in -> (entry_exchange + substep) -> copy_out -> normal-width exit exchange (in the caller). 4. exit_data — release GPU present table entries. 5. destroy — free host memory.

public subroutine bt_wide_substep(bt_wide, bt_work, n_steps, dt_inner, bc, t, tide)

Wide-halo (march-in) entry point for the nonlinear barotropic fast loop. Unpacks the wide shadow arrays (w_*, wide grid, the static wide metrics and f_corner_w) and forwards them to barotropic_substep_nonlinear with bt_halo = bt_wide%bt_halo, so the ~20-array plumbing lives here once rather than at the call site. bc and t propagate by absence; t is the outer-step model time the tidal open-edge target is evaluated at (as on the one-rank bt_halo = 0 path). tide selects the wide eta_forcing (bt_wide_set_eta_forcing ran this solve). Interior twin: barotropic_substep_nonlinear_interior.

private subroutine bt_wide_copy_in_impl(this, grid, bt_eta, bt_H_ref, bt_ubt, bt_vbt, bt_ubt_prev, bt_vbt_prev, bt_rem_u, bt_rem_v, force_u, force_v, dy_cu_bt, dx_cv_bt)

Non-polymorphic copy_in body. Offset = bt_halo: w_X(iw, jw) = X(clamp(iw-off), clamp(jw-off)) over the FULL wide extent — the inner band is a direct offset copy; the outer bt_halo ring is a clamped-index (constant-extrapolation) fill. The ring fill matters: without it the ring carries stale end-of-fast-loop values from the previous stage (H_ref = 0, eta from t-1), which at a PHYSICAL (non-seam) edge is never refreshed by any exchange and free-runs an inconsistent zero-depth integration that blows up in O(25) outer steps. At an MPI seam the ring is immediately overwritten with true neighbour data by entry_exchange, so the clamped fill only governs physical edges — the same sane ghost-band construction the v1 normal-width path gets from its own ghosts. Scratch / accumulator arrays (w_eta_new, w_ke, w_eta_sum, …) do not need copy-in — the substep initialises them.

private subroutine bt_wide_entry_exchange(this)

Fills the wide ghost band before the fast loop with ONE packed exchange (eta, ubt, vbt, rem_u, force_u, rem_v, force_v). H_ref is exchanged once, at the first call. The previous-substep velocities are not exchanged: the fast loop re-seeds them from ubt/vbt over the whole wide array when bebt > 0 and never reads them otherwise (their coefficient is 0). Under porous barriers / closed faces the two per-solve BT widths (w_dy_cu, w_dx_cv) follow in one wide face exchange each (the packed set is full at three x / y arrays). Counter effect: +1 bt_packed per call (+1 centre_2d on the first; +1 face_x_2d, +1 face_y_2d more when the widths are refreshed). Dispatches to the non-polymorphic _impl body.

private subroutine bt_wide_init(this, grid, metrics, f_corner, refresh_widths, ring_poison, eta_forcing_on)

Allocate the wide shadow state and fill its STATIC fields from their owners. Builds grid_w (same nx_phys/ny_phys as grid, nghost = grid%nghost + bt_halo). Every metric array the fast loop reads, and f_corner, is the model’s own array offset-copied into the wide extent (the outer bt_halo ring is a clamped copy, finite and never read at a physical edge: the substep’s insets re-anchor every array-edge closure at the NORMAL array edge), then ONE host-side wide exchange gives every seam / periodic ghost its owner’s value. Land masks, wall-ghost zeros, file-based (supergrid) metrics and closed-face widths therefore arrive exactly as the one-rank bt_halo = 0 kernel sees them.

private subroutine exchange_corner_host(c, ng)

Wide host exchange of a CORNER-staggered field c(nxt+1, nyt+1) (no corner primitive exists in the halo module). A corner array is x-face-like in x and, in y, differs from a cell-centred row index only by one extra row: its rows map to global rows exactly as cell rows do. So the x-face exchange applied to rows 1:nyt, then to rows 2:nyt+1 (as two (nxt+1, nyt) temporaries), gives every row of c its owner’s value (the second pass supplies the last row), with the seam column duplicated as for a face and the two-pass corner rule, periodic wrap included. Host, setup only.
