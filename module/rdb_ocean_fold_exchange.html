Owner-routed north-fold exchange for an east-west split north rank row, plus the px-dispatching single-field fold entry points (ocean_fold_north_*): px = 1 keeps the local kernels of rdb_ocean_fold verbatim, px > 1 always uses the exchange (the self-mirror tile through a local copy).

TWO CONTEXTS. The routing plan, its device index lists and the message buffers depend on the ghost width, so the exchange keeps one context per width: FOLD_CTX_NORMAL (nghost, every state-level fold) and FOLD_CTX_WIDE (nghost + bt_halo, the wide-halo barotropic march-in, built only when bt_halo > 0). The wide fold is the SAME mechanism on a plan built for the wider band (plan fold_plan_build(ni, px, nghost + bt_halo, rx)): every value still comes from the tile that owns the mirror point. The group protocol takes an optional ctx (default normal); a group is opened, packed, exchanged, unpacked and closed on ONE context.
