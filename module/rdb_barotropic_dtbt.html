bt_dtbt_dt_max

The forward-backward barotropic substep (continuity on the BEBT- projected face velocity, then the momentum update with the new elevation and an explicit Coriolis term) is stable for

dt_bt^2 <= dt_max(i,j)^2  at every wet cell, with

1/dt_max^2 = 1/2 (1 + 2 bebt) [ (1/A_T) ( g D_E dy_E/dx_E + g D_W dy_W/dx_W
                                        + g D_N dx_N/dy_N + g D_S dx_S/dy_S )
                                + f_NE^2 + f_NW^2 + f_SE^2 + f_SW^2 ].

The bracketed gravity-wave sum is the squared highest wave frequency the cell’s four faces can carry; the 1/2 (1 + 2 bebt) factor is the stability limit of the projected scheme (Shchepetkin & McWilliams 2005; Hallberg & Adcroft 2009), and the corner f^2 terms are the explicit Coriolis rotation.

Mapping onto the BT arrays: D_f dy_f is the BT continuity face AREA the substep itself uses – the face thickness 0.5 (D_a + D_b) of the two adjacent column depths D = sum_k h_layer times dy_cu_bt / dx_cv_bt – divided by the centre-to-centre distance 1/idxCu / 1/idyCv. Porous narrowing enters only through the _bt widths the caller passes: the PER-STEP re-derivation (dtbt_reset_period) sees the narrowing the porous refresh applied, but the SETUP-time value is formed before that refresh, from the un-narrowed widths – the smaller, conservative dt_max. A face is open only when BOTH adjacent cells are wet. g is the substep gravity bt_work%g_bt (full gravity unless a reduced-gravity / SAL correction was configured).

The step actually used is |dtbt| * min_cells dt_max for dtbt < 0 (dtbt = 0 means -0.98), or dtbt seconds for dtbt > 0; n_inner = ceiling(dt / step) and the substep is dt / n_inner.

public subroutine bt_dtbt_dt_max(nx, ny, nz, i0, i1, j0, j1, h, wet, dy_cu, dx_cv, idx_cu, idy_cv, iarea_t, f_corner, g, bebt, on_device, dt_max)

Domain-local dt_max = min over wet cells in [i0:i1, j0:j1] of the cell limit; huge if no wet cell has a nonzero limit (the identity of the cross-rank min). on_device = .true. runs the do concurrent reduction (every array device-present); .false. is a plain host loop for configure time, before the state is mapped. The device branch spells the cell body out inline: the same arithmetic reached through the nested routine seq call bt_dtbt_cell_inv2 returned a wrong (too large) dt_max on nvfortran -stdpar=gpu (155 s against the host 74.6 s on the 1-degree grid) while every input array matched the host copy; test_ocean_bt_cfl pins the device branch against the host one.
