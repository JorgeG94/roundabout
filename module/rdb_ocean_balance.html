ocean_balance_velocity sets the layer velocities u_face_x_layer, v_face_y_layer in GEOSTROPHIC balance with the density field the state already carries. The pressure gradient is not re-derived here: the model’s own kernel (ocean_pressure_force_compute, whichever &ocean_pgf_nml form is configured) is run on the current h_layer / rho_layer, so the balance is exact for the discrete operator the dynamics will integrate (a balanced start does not radiate the discretisation’s own imbalance).

Balance. With a = (a_x, a_y) the TOTAL horizontal pressure acceleration (the layer PGF plus whatever free-surface term the barotropic substep will add, see below), the steady state of

du/dt = +f v + a_x, dv/dt = -f u + a_y

is

u = a_y / f , v = -a_x / f .

On the C-grid a_x lives on u-faces and a_y on v-faces while u needs a_y, so each component takes the 4-point average of the other component’s face accelerations (the two faces either side, on each of the two adjacent rows/columns):

u(i,j) = (1/f_u(i,j)) * 1/4 [ a_y(i-1,j) + a_y(i,j) + a_y(i-1,j+1) + a_y(i,j+1) ] v(i,j) = -(1/f_v(i,j)) * 1/4 [ a_x(i,j-1) + a_x(i,j) + a_x(i+1,j-1) + a_x(i+1,j) ]

f_u = (f_corner(i,j) + f_corner(i,j+1))/2, f_v = (f_corner(i,j) + f_corner(i+1,j))/2 (corner (i,j) is the SW corner of cell (i,j)). These are the discrete operator seed_balanced_vortex_ic uses on its analytic potential: differencing a corner-averaged phi is identical to this 4-point average of the face differences. At array edges where one of the four faces does not exist the available ones are averaged.

Free surface. The Montgomery / FV-lite / FV-Wright forms are measured from the free surface and carry no -g grad(eta); the barotropic substep supplies it with bt_work%g_bt. FV-MOM6 and gprime carry pgf_free_surface_gravity(pgf) of it themselves. The net term added here is therefore -(g_bt - g_pf) grad(eta) with eta = sum_k h - bt_H_ref, so the balance sees exactly the acceleration the split step will apply.

Reference level. ref_level = "keep_h" trusts the thickness the caller supplied (their eta). "bottom_rest" (default) first chooses the sea surface that leaves the BOTTOM pressure anomaly zero (no net load on the bed: no deep flow, a surface-intensified balanced eddy, as in the vortex context of McWilliams & Flierl, 1979):

eta(i,j) = -(1/rho_0) sum_k (rho_k - rho_ref,k) h_k

with rho_ref,k the per-layer MEDIAN density over the wet interior (the far-field background of a compact anomaly; a plain mean would add a uniform offset equal to the anomaly’s area-mean, which leaves the velocities unchanged but shifts the absolute sea level). Each column is then stretched uniformly, h_k <- h_k (b + eta)/sum h. Only h_layer is scaled: tracers are stored as concentration c, so the content h*c scales with h and c is left untouched (a sigma-like choice, not an isopycnal one).

Residency (GPU -gpu=mem:separate). Must be called AFTER ocean_state_enter_data (engine_enter_data): the PGF and EOS kernels are do concurrent over device-mapped state and scratch. The HOST arrays h_layer and every tracer c are the inputs and are pushed to the device first (update device on leaf arrays only); the host u/v/hu/hv/h_layer/ c/rho_layer are the outputs and are pushed/pulled symmetrically, so on return host and device agree. Never an aggregate derived-type update.

Scope. Geostrophic only (BALANCE_GRADIENT is reserved and fails loud). Cartesian and spherical lon-lat grids; refuses tripolar / supergrid, porous barriers, wet/dry, ice-shelf cavities, and any face where |f| < f_min (the equatorial band has no geostrophic solution). Every refusal returns an error status and leaves u, v (and h) untouched.

Decomposed domains (bitwise identical to one rank). Every stencil above is local; the only global quantities are (i) the per-layer MEDIAN rho_ref,k, computed on more than one rank by an exact bisection over the ordered bit patterns of the wet interior densities (global counts via an exact allreduce, so the result is the SAME element the one-rank quickselect returns), (ii) the |f| floor (global min) and (iii) the bottom-rest failure flag (global max, so every rank returns the same status). The inputs are first made seam-valid (host exchange of h, tracers, and the prescribed rho when thermodynamics is off). Output u, v, hu, hv ghosts are NOT exchanged (the one-sided edge average at a tile edge differs from the neighbour’s owned value). The rebaseline tail of ocean_balance_apply refreshes only h, u, v and the tracer seam ghosts (refresh_seam_ghosts) and then pushes the host hu/hv, so the device hu/hv seam ghosts keep the balance’s one-sided tile-edge values until the first step recomputes them (nothing reads them before that). The decomposed branch is gated by the balance_* cases of test_ocean_decomp_bitid_mpi; its only source caller chain (ocean_balance_apply <- the C API) is single-rank, so it is reachable today only from that test. On one rank the ghost-cell velocities come out of the same stencil on the ghost thickness/density.

private subroutine global_lower_median(a, n, m, n_global)

Lower median over the union of every rank’s a(1:n) (collective), identical to lower_median on the gathered array: the smallest value x with count(a <= x) >= (N + 1)/2, found by bisection on the monotone int64 image of the IEEE bit pattern. Counts ride the exact real64 allreduce (halo_allreduce_sum_i8). n_global = N; m is untouched when N = 0. Returns the k-th order statistic, k = (N + 1)/2, with bits identical to the one-rank selection, except that -0.0 and +0.0 share a key and come back as +0.0. Non-finite input is not guarded (densities are full rho).
