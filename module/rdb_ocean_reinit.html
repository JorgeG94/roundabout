engine_setup builds the built-in initial condition and THEN takes a series of snapshots and derivations of it (sponge reference, pseudo-salt seed, land-face masking, seam ghosts, rho_layer). A caller that overwrites h/u/v/tracers on the finished handle leaves all of them describing the OLD initial state. ocean_rebaseline_apply redoes the ones that matter physically, in the order engine_setup runs them, on the current prognostics. (The preferred route is the staged path, rdb_ocean_ic_inject, which gets this right by construction.)

Device discipline (-gpu=...,mem:separate)

The caller has already drained the windowed tracer accumulator and refreshed the HOST copies of h, u, v and every c from the device, so the host is authoritative on entry. Every host write below is followed by an !$acc update device(<leaf array>); every value a device kernel produced (rho_layer, bt_eta, the seam-wrapped state) is pulled with !$acc update self(<leaf array>) before the host reads it. Never an aggregate: only leaf component arrays are named. All of it is inert on a host-only build.

Known limit

The tidal-mixing static fields are folded with depth = sum(h_layer) at setup and are NOT re-folded here (the error is O(eta/H) after a set_h). The wet/dry hysteresis mask is likewise left to the first step.

public subroutine ocean_balance_apply(state, grid, cfg, mode, ref_level, thermo_active, reseed_pseudo_salt, ierr)

ocean_balance_velocity (device-resident state, host authoritative on entry) followed by ocean_rebaseline_apply, so the sponge reference, land mask, pseudo-salt and eta describe the balanced state. On a refusal ierr /= OCEAN_STATUS_OK, the error ring carries the reason and nothing was modified.

public subroutine ocean_rebaseline_apply(state, grid, thermo_active, reseed_pseudo_salt)

Steps 3-8 of rdb_ocean_rebaseline (the API wrapper does the precondition checks, the windowed-tracer flush and the host refresh first). Decomposition-safe (exercised decomposed by the balance_* cases of test_ocean_decomp_bitid_mpi); the C API handle that reaches it is single-rank.
