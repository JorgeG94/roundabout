What this is. exp, log, sin, cos, tan, atan, atan2, tanh, cosh, acosh, pow (real ** real), cbrt and erfc, written ONLY in IEEE + - * /, sqrt, anint/nint, scale/exponent/fraction on finite operands and compile-time tables. The value of safe_exp(x) is a function of x alone: it does not change with the element’s position in a vector body or remainder loop, with the tile or rank the element lives on, with the compiler’s vector math library (libmvec, libpgmath), or with the optimisation level. The intrinsic exp(x) has none of those guarantees – a decomposed run and a one-rank run can round the same cell differently – which is why a model kernel that must reproduce bitwise across decompositions calls these instead.

Always on. There is no build option and no namelist knob: the safe_* names ARE the reproducible implementations.

One source text. The bodies live in rdb_safe_math_{core,pow,trig,atan,hyp,erfc}.inc (constants in rdb_safe_math_consts.inc, included once) so a kernel module can #include its own module-local copy (the form every toolchain inlines into a do concurrent body); this module includes the same text and exports elemental wrappers for host code, setup code and tests. Both carry !$acc routine seq.

Special values propagate (NaN in, NaN out; exp(+Inf) = +Inf, log(0) = -Inf, log(-1) = NaN, pow per IEEE-754/C99 except that a NaN argument always gives NaN) – no huge sentinels. No function returns a subnormal: every result with |r| < tiny is exactly zero (the sign of a flushed zero is not guaranteed: ifx returns +0 where gfortran keeps the sign) (the flush rule, rdb_sm_flush), so compilers that flush denormals and those that do not agree. Subnormal ARGUMENTS: log of one is finite unless the compiler is in denormals-are-zero mode (then -Inf); cbrt reads it as 0; the others see whatever the compiler gives them and flush their result. Valid ranges are in each function’s docstring; sin, cos, tan return NaN beyond 1.6e6 rad (a phase that grows with time, e.g. tidal omega*t, must be reduced on the host with modulo(phase, 2*pi) first).

Contraction policy (what is and is not bit-reproducible). The library adds NO per-file compiler flag: it follows each build’s global fused-multiply-add setting. The CPU builds of this repository compile with contraction OFF (gfortran -ffp-contract=off, nvfortran -Mnofma; ifx needs -no-fma); there the values are bitwise the same on every compiler and at every vector position, and the golden-bit test tests/test_safe_math.F90 pins them. The GPU build (and any contracting build) differs from that table by 1-2 ulp on some arguments, so the test does NOT assert the table there; it asserts that device array results equal device scalar calls of the same included copy, the ulp bounds, and the special values. Working precision must be real64; the constants are real64 splits and the build stops otherwise (SM_WP_IS_REAL64).

Not provided: sqrt is IEEE-exact on every target and needs no wrapper beyond safe_sqrt; integer powers x**n are exact products.
