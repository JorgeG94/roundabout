ocean_zinit_config_t

type, public :: ocean_zinit_config_t

Z-level T/S initial-condition overlay (&ocean_zinit_nml, capability A2). Reads pre-regridded T/S from a model-grid NetCDF and interpolates linearly in depth onto the seeded layer-centre depths, overwriting any analytical T/S. All defaults preserve bit-identity: enable = .false. is a no-op. Design + MOM6 divergences: local_archive/specs/a2_zinit_spec.md.
