ocean_sponge_t

type, public :: ocean_sponge_t

Map-driven sponge state: per-cell Idamp [1/s] + a 3-D reference state. See the module docstring for the physics + the MOM6 divergences. Value-semantics slot (no CS pointer, no associated(CS) guards): a plain handle owned by ocean_state_t.
