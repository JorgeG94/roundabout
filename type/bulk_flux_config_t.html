bulk_flux_config_t

type, public :: bulk_flux_config_t

Free-standing configuration bundle for the bulk-flux kernel. NOT currently registered on cfg%ocean (see the module’s “Seam for C2c” note) — a standalone type so a future &ocean_bulk_ flux_nml reader has an obvious target, and so a caller that does wire it up today (e.g. a test or a bench) has one place to hold the knobs rather than a scatter of bare arguments.
