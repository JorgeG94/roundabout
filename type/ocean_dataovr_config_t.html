ocean_dataovr_config_t

type, public :: ocean_dataovr_config_t

&ocean_dataovr_nml: file-backed surface forcing (PR-15, the A3 keystone consumer). Binds time-varying NetCDF fields, through the shared PR-14 reader (&ocean_data_nml), onto the surface stress and surface-flux slots. enable = .false. registers nothing ⇒ ocean_data_input_update_all stays a no-op ⇒ bit-identical.

The heat/freshwater tags write the surface-flux COMPONENT fields, not Q_heat/Q_salt directly, because ocean_surface_flux_assemble fully overwrites those two from the components every thermo step — a direct write would be silently clobbered. They therefore require &ocean_forcing_nml enable_components = .true. (fail-loud otherwise). Sign conventions are inherited from the component slots: evap <= 0, lprec >= 0, both kg/m^2/s.
