ocean_diag_nc_stream_t

type, public :: ocean_diag_nc_stream_t

NetCDF output stream state. Carried inline on ocean_diag_t so the diag module stays NetCDF-free (no use netcdf here); the actual file operations live in rdb_ocean_diag_netcdf which manipulates these fields.
