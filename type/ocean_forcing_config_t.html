ocean_forcing_config_t

type, private :: ocean_forcing_config_t

&ocean_forcing_nml: PR-12 surface-flux component-set gate. Default OFF ⇒ bit-identical (no component array allocated, no assembler kernel runs; ocean_surface_flux_t%Q_heat/Q_salt are filled exactly as &ocean_thermo_nml always has).
