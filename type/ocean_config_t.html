ocean_config_t

type, public :: ocean_config_t

All ocean-path knobs, nested by concern. Parallel to the state composition pattern (ocean_state%dyn, %vcoord, etc.). Read-side: see the per-sub-nml blocks in read_config. Call-side: cfg%ocean%bt%use_cont_type, cfg%ocean%pgf%form, etc.
