ocean_atm_forcing_config_t

type, public :: ocean_atm_forcing_config_t

&ocean_atm_forcing_nml: JRA55-do-style prescribed atmospheric state (PR-C2c), read through nine register_2d_filelist instances and driving the bulk-flux-computed ocean/ice surface fluxes. Default enable = .false. registers nothing ⇒ bit-identical. Field tags throughout are the 9 CMOR/JRA55-do names: tas, huss, uas, vas, psl (instantaneous states), rlds, rsds, prra, prsn (interval-mean fluxes).

      character(len=256) :: filelist_tas = ""

         !! list for `tas` (air temperature). Blank = fail loud when
         !! `enable = .true.`.
      character(len=256) :: filelist_huss = ""
         !! Filelist for `huss` (specific humidity).
      character(len=256) :: filelist_uas = ""
         !! Filelist for `uas` (eastward 10 m wind).
      character(len=256) :: filelist_vas = ""
