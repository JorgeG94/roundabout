ocean_cavity_flux_t

type, public :: ocean_cavity_flux_t

Ice-shelf basal-melt slot: the 2-D interface state plus the parameter bundles the kernel is called with.

Every array is (nx_total, ny_total) when enable, (1,1) otherwise — the z_draft gating convention, latched in ocean_state_init_from_config BEFORE init so the allocation gate can read it.
