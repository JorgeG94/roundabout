ocean_tdrag_config_t

type, public :: ocean_tdrag_config_t

&ocean_tdrag_nml — ICE-SHELF TOP drag, the mirror of &ocean_bdrag_nml at k = nz. Requires &ocean_cavity_dyn_nml enable (without a draft there is no ice base and cover_frac is identically zero, so the kernel would be a no-op with a cost). Default enable = .false. ⇒ the slot is a placeholder, no kernel runs, every path is bit-identical.
