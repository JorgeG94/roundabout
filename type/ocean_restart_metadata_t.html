ocean_restart_metadata_t

type, public :: ocean_restart_metadata_t

Grid/coordinate/tracer fingerprint validated on read. Distinct from the decomposition metadata (px/py/dims) so a file built with a different vertical resolution, ghost width, vcoord, or tracer set is rejected loudly rather than silently mis-mapped.
