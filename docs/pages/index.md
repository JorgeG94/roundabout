These are the **API reference** docs, generated by FORD from the `!!`
docstrings in the Fortran source. They describe every module, derived type
and procedure in the solver.

For the **user guide** — theory, discretisation, vertical coordinates, the
pressure-gradient forms, closures, running simulations, the Python driver
and the validation suite — see the Sphinx site, which is maintained
separately from this reference.
