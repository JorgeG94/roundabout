public interface rdb_debug_chksum

Grid-location-aware checksum: derives the array extents from grid + loc (no hand-written bounds at the call site), runs the device-side reductions, and emits one CHKSUM row. Resolves by rank — 3D field trio / 2D BT-work variant.

private subroutine rdb_debug_chksum_3d(grid, arr, label, field, stage, step, probe, loc)

Location-aware 3D checksum: derives (nx, ny) from grid + loc and nz from the array, so a new instrumentation site is one line with no hand-written bounds. Gated by the probe window.
